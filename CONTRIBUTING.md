# Contributing

Thanks for your interest in the TEssentials core.

## What is welcome

- **Bug reports.** Open an issue with the core version (or commit), the input that goes wrong (players,
  ratings and games, as small as you can make it), the result you got and the result you expected.
  For rules questions, name the FIDE regulation you are comparing against.
- **Questions and ideas.** Open an issue or a discussion.

## What is not accepted yet

**Code pull requests.** The terms under which outside contributions are accepted are not settled yet,
so pull requests will be closed without review for now. This is not about the quality of your work, I am just figuring out what I want out of this project for now.
